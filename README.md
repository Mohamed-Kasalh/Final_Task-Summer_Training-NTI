# Final Task - Summer Training NTI 🌍

Final project for the **ITIDA–NTI Summer Training** program (Frontend Web Development track). A multi-page travel & tourism website that lets users browse destinations, hotels, and travel packages.

## 📄 Pages

| Page            | Description                                   |
| --------------- | --------------------------------------------- |
| `index.html`    | Home page — landing/hero section and overview |
| `places.html`   | Browse travel destinations/places             |
| `hotels.html`   | Browse and view hotel listings                |
| `packages.html` | Browse available travel packages/deals        |

## 🛠️ Built With

- **HTML5** — page structure & content
- **CSS3** (`style.css`) — custom styling and layout
- Responsive layout techniques (Flexbox / Grid)

## 📁 Project Structure

```
Final_Task-Summer_Training-NTI/
├── Images/          # Site images and assets
├── index.html       # Home page
├── places.html       # Destinations page
├── hotels.html       # Hotels page
├── packages.html      # Packages page
└── style.css         # Global stylesheet
```

## 🚀 Getting Started

No build steps required — it's a static site.

1. Clone the repository
   ```bash
   git clone https://github.com/Mohamed-Kasalh/Final_Task-Summer_Training-NTI.git
   ```
2. Open `index.html` in your browser (or use a Live Server extension in VS Code).
